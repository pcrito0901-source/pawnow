PawNow プライバシーポリシー

田中琉斗（以下「当社」）は、iOS アプリ「PawNow」（以下「本アプリ」）における
利用者の個人情報の取扱いについて、以下のとおり定めます。

1. 基本方針

本アプリは、ペットの写真を、利用者が選んだ少人数のグループの中だけで交換するためのものです。
公開のソーシャルネットワークではなく、投稿が不特定多数に公開されることはありません。

当社は、本アプリの提供に必要な範囲を超えて個人情報を取得しません。
また、利用者の写真・コメント・一言（キャプション）の内容を、分析基盤や広告事業者に送信しません。

2. 取得する情報

2.1 アカウント情報

本アプリは Apple ID または Google アカウントによるサインインのみを提供します。
当社がパスワードを取得・保管することはありません。

プロバイダ種別Apple / Google のいずれか認証
プロバイダ内の識別子Apple / Google が発行する識別子同一利用者の判別

メールアドレスの提供は必須ではありません。Apple の「メールを非公開」を利用した場合、
当社には転送用のアドレスのみが渡ります。

2.2 利用者が作成するコンテンツ

  • 写真（本アプリ内のカメラで撮影されたもの）
  • 写真に添える一言、コメント、定型リアクション
  • ペットのプロフィール（名前、種別、写真、任意で誕生日・家に来た日）
  • ペットの健康の記録（体重、お薬と飲ませた記録、通院、ワクチン）
  • グループの名称、メンバー構成、毎日の通知の時刻
  • グループのメンバーへの「いま見たい」のお願い
  • 投稿やコメントの通報（理由はあらかじめ定めた選択肢から選びます）と、ブロックの記録

グループに投稿できる写真は、本アプリ内のカメラで撮影したものに限ります。
端末の写真ライブラリから選んだ写真を投稿することはできません。
ペットと利用者のプロフィール写真は、本アプリ内のカメラで撮影するほか、
端末の写真ライブラリから選ぶこともできます。その場合も、当社が受け取るのは利用者が選んだ写真だけです。

2.3 利用状況の記録（分析）

本アプリはサービス改善のため、利用状況を記録します。記録するのは以下の17種類の操作のみです。

app_opened / today_feed_viewed / day_choice_selected / post_shared /
album_viewed / reaction_added / now_request_sent / now_request_answered /
paywall_viewed / purchase_completed / group_created / invite_created /
invite_shared / invite_opened / group_joined / onboarding_completed /
paywall_dismissed

各記録に添える情報は、すべて数値・真偽値・あらかじめ定めた選択肢のいずれかです。
自由に入力された文字列を格納できる場所が、仕組みとして存在しません。

分析基盤へ送信しないもの（設計上、送信できません）

  • 写真そのもの、および写真を取得できるURL
  • 一言、コメントの本文
  • ペットの名前、利用者の表示名、メールアドレス
  • グループの招待コード
  • ペットの健康の記録

分析上の利用者識別には、メールアドレスや表示名とは無関係な不透明な識別子を用います。

記録の送信先は PostHog Inc.（米国）の分析基盤です。
通信の性質上、送信元の IP アドレスは PostHog に届きますが、保存しない設定にしています。
また、IP アドレスから所在地を推定させない指定を、すべての記録に付けています。

2.4 課金情報

購入は Apple の App Store を通じて行われます。
当社がクレジットカード番号等の決済情報を取得することはありません。
当社が保持するのは、有料機能を利用できる状態にあるか否か、購入したプランの種別、
および課金の状態の変化について RevenueCat から届く通知の内容（購入・更新・解約などの種類、日時、商品、取引の情報）の記録です。
また、2.3 の記録として、購入が完了したことと、プランの種類および無料体験の開始かどうかを分析基盤に送信します。

3. 利用目的

  1. 本アプリの機能の提供（投稿、閲覧、アルバム、グループ、通知、健康の記録）
  2. 有料機能の提供可否の判定
  3. 不具合の調査および対応
  4. サービスの改善（2.3 の範囲）
  5. 重要なお知らせの連絡

当社は、取得した情報を広告の配信や、利用者の行動追跡のために利用しません。
また、第三者に販売しません。

5. 写真の保護

写真は暗号化された通信経路を通じて保管され、取得には短時間で失効する署名付きのURLが必要です。

本アプリには「当日の写真は、自分もその日の写真を出した人にだけ見える」という仕組みがあります。
この判定はサーバー側で行われ、条件を満たさない利用者にはそもそも写真のURLが発行されません。
画面上で隠しているのではなく、データが渡らない構造です。

グループを離脱した場合、そのグループの写真は当日分・過去分ともに閲覧できなくなります。
自身が撮影した写真は、自身のペットのアルバムに残ります。

6. 保存期間と削除

  • 写真および記録は、利用者が削除するまで、またはアカウントを削除するまで保存されます
  • 投稿の削除は、写真の実体を保管先からも削除します
  • 有料プランを解約した場合も、それまでに作成された記録は引き続き閲覧できます
  • アカウントを削除した場合、アカウント情報および利用者が作成したコンテンツを削除します

7. 通知

本アプリは、1日1回グループ全員に同時に届く通知を送信します。
通知の時刻はグループごとに決まっています。
グループごとに、通知を受け取るかどうかを選べます。
このほか、「いま見たい」のお願いとその返事、および利用者が登録したお薬のリマインド（登録した本人にだけ届きます）を通知します。
通知そのものの受信可否は、端末の設定でいつでも変更できます。

通知を届けるため、端末ごとの通知用のトークンを保存し、
Expo（650 Industries, Inc.）の配信の仕組みを通じて Apple に渡します。

8. 利用者の権利

利用者は、当社が保有する自身の個人情報について、開示・訂正・利用停止・削除を請求できます。
ご請求は下記の窓口までご連絡ください。

利用状況の記録（2.3）については、アプリのマイページの「利用状況をおくる」をオフにすると、いつでも停止できます。
停止すると、以後の記録の送信を行いません。

9. 年齢に関する制限

10. 本ポリシーの変更

本ポリシーを変更する場合、本アプリ内または当社ウェブサイトにて周知します。
重要な変更については、事前に通知します。
